# Helpdesk Fun: User Workstation Nightmares

## Objective

Resolve user-reported Windows workstation issues and restore
expected desktop settings, connectivity, and access to a
shared network resource.

## Tools and Technologies

- Windows Settings
- Windows File Explorer
- Network discovery
- Network shares and mapped drives
- Proxy settings

## Summary of Work

I corrected workstation settings affecting mouse behavior
and desktop icon visibility. I also enabled network discovery
to locate a file-sharing server and configured a mapped
network drive with reconnection at sign-in.

To address the reported connectivity issue, I reviewed and
adjusted the workstation's proxy configuration. I checked
the updated settings and confirmed that the mapped drive
and desktop icons were visible.

## Skills Practiced

- Troubleshooting Windows workstation settings
- Correcting mouse and desktop display preferences
- Configuring network discovery
- Mapping shared network resources
- Reviewing proxy settings
- Verifying user-environment changes
