# Preventative Protection: Thwarting the Imminent Threat

## Objective

Strengthen the security of a domain controller facing an
imminent external threat through system maintenance and
configuration hardening.

## Tools and Technologies

- Windows Server
- Windows PowerShell
- Windows Control Panel
- Windows Update
- SMB protocol configuration

## Summary of Work

I performed preventative security maintenance on a Windows
domain controller by applying available updates and reviewing
its file-sharing protocol configuration.

Using PowerShell, I inspected the server's configuration and
disabled a legacy protocol as part of the hardening work.
I verified that the updates installed successfully and
confirmed that the configuration change took effect.

## Skills Practiced

- Applying Windows Server updates
- Reviewing server configuration with PowerShell
- Hardening file-sharing protocol settings
- Reducing unnecessary legacy functionality
- Verifying security configuration changes
