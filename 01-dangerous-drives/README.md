# Dangerous Drives

## Objective

Inspect a USB drive of unknown origin for malicious files and
remove detected threats while preserving the integrity of
other files.

## Tools and Technologies

- ClamWin Antivirus
- Windows File Explorer
- Windows workstation
- USB removable storage

## Summary of Work

I used ClamWin to scan a USB drive and reviewed its detection
results to identify files requiring removal. I used Windows
File Explorer to locate and remove detected files and inspected
hidden files as part of the investigation.

The exercise combined antivirus scanning with manual file
inspection, with an emphasis on removing infected files
without disrupting the files protected by the lab's
integrity checks.

## Skills Practiced

- Scanning removable media for malicious files
- Interpreting antivirus detection results
- Locating detected files using scan-report information
- Inspecting hidden files in Windows
- Performing targeted file removal
- Validating remediation and file integrity
