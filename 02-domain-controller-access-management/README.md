# Interns & HR on the Domain Controller

## Objective

Address excessive access to organizational resources by
reviewing domain accounts, managing security-group membership,
and restricting access to shared folders and workstations.

## Tools and Technologies

- Active Directory Users and Computers
- Windows Server Manager
- Windows File Explorer
- Windows Server
- Linux terminal
- Samba file-sharing services

## Summary of Work

I used Active Directory Users and Computers to manage domain
accounts and security groups. My work included disabling an
account that no longer required access, creating groups,
organizing users by access requirements, and updating
administrative group membership.

I also applied workstation logon restrictions and adjusted
shared-folder permissions to limit access to the appropriate
groups and administrators. On the file-sharing server, I
restarted the relevant Samba services as part of the
configuration work.

Throughout the exercise, I checked account status, group
membership, logon restrictions, and folder permissions to
confirm that the changes were applied.

## Skills Practiced

- Administering domain user accounts
- Creating and managing security groups
- Reviewing and updating group membership
- Applying group-based access controls
- Configuring workstation logon restrictions
- Managing shared-folder permissions
- Managing Linux file-sharing services
- Verifying account and access-control changes
